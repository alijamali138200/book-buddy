# کتاب‌یار 📖

دستیار هوش مصنوعی برای پیشنهاد و گفتگو درباره کتاب، ساخته‌شده با Streamlit و Gemini API.

## قابلیت‌ها
- بر اساس سلیقه، ژانر یا حال‌وهوای کاربر، کتاب پیشنهاد می‌دهد
- درباره یک کتاب خاص گفتگو و تحلیل ارائه می‌دهد
- پاسخ‌ها به‌صورت زنده (استریم) نمایش داده می‌شوند

## نحوه اجرا

۱. نصب کتابخانه‌های لازم:

pip install -r requirements.txt


۲. اجرای برنامه:

streamlit run book_buddy_streamlit.py


۳. یک کلید رایگان از [Google AI Studio](https://aistudio.google.com/app/apikey) بسازید و در نوار کناری برنامه وارد کنید.

## تکنولوژی‌ها
- Python + Streamlit برای رابط کاربری
- Gemini API (مدل gemini-3.8-flash) برای پاسخ‌های هوش مصنوعی
